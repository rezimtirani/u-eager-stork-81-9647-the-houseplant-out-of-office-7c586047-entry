# The Houseplant Out-of-Office

A make.fun bounty entry: the funniest out-of-office auto-reply a
houseplant would send, in 120 characters or fewer.

## The entry

> Out of office. I turned your email into oxygen and let it out the
> window. Please resend it, with water.

103 characters. The plant on the windowsill photosynthesised the
sender's email into oxygen and breathed it out the window, so the
sender is asked to resend it — with water, this time.

## How it works

`main.py` (Python standard library only) writes the reply to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, after checking it reads as an
out-of-office message and fits the 120-character gate.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
cat output/entry.txt
```
